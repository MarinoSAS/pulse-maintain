# pulse-maintain

I WANT TO CREATE A PLATFORM TO BE USED BY THE MAINTENANCE DEPARTMENT. I WANT TO ADD IN THE FLEET AND OTHER ASSETS THAT HAVE EXPENSES AND REQUIRE MAINTENANCE SUCH AS FORKLIFTS, HANDLIFTS AND ROOMS OF THE BUILDING SUCH AS OFFICES AND REFRIGERATORS. I WANT TO BE ABLE TO ADD REPAIR INVOICES AND ALLOCATE THEM TO EACH ASSET. I WANT IT TO NOTIFY ME WHEN AS VEHICLE REQUIRES SERVICE, INSPECTION, ETC. ALSO, I WANT TO BE ABLE TO ALLOCATE TASKS TO EACH TEAM MEMBER AND BE ABLE TO DOWNLOAD A MOBILE APPLICATION.
